# Adrobot: Тестовое задание по интеграции с Keitaro

Этот сервис представляет собой FastAPI-приложение для управления рекламными кампаниями в трекере Keitaro. Он позволяет создавать новые кампании со сложной структурой потоков и редактировать существующие.

## Требования

- Python 3.13+
- [uv](https://github.com/astral-sh/uv) (для управления зависимостями и запуска)

## Установка и запуск

1.  **Клонируйте репозиторий**
    ```bash
    git clone <URL вашего репозитория>
    cd test_task_ads_tracking
    ```

2.  **Настройте переменные окружения**

    Проект использует файл `.env` для хранения ключей API и настроек. Создайте его, скопировав из примера:
    ```bash
    cp .env.example .env
    ```
    Откройте файл `.env` и **обязательно** вставьте ваши актуальные `KEITARO_API_KEY` и `KEITARO_API_URL`.

3.  **Установите зависимости**

    `uv` создаст виртуальное окружение и установит в него все зависимости, указанные в `pyproject.toml`.
    ```bash
    uv pip install -r requirements.txt
    ```

4.  **Примените миграции базы данных**

    Этот шаг создаст файл `app.db` и в нём таблицу `action_logs` для логирования действий.
    ```bash
    uv run alembic upgrade head
    ```

5.  **Запустите приложение**
    ```bash
    uv run uvicorn app.main:app --reload
    ```

После запуска приложение будет доступно по адресу `http://127.0.0.1:8000`. Документация API (Swagger UI) находится по адресу `http://127.0.0.1:8000/docs`.
